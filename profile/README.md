<h1 align="center">Project Chronicles</h1>

<p align="center">A community-built C++20 MMORPG emulator.<br>Explore the protocol, build stateful systems and help bring the researched world to life.</p>

## Choose your project

| Component | Responsibility |
| :--- | :--- |
| [**Login server**](https://github.com/Project-Chronicles-Emulator/login-server) | Accounts, player sessions, launcher grants and world admission |
| [**Game server**](https://github.com/Project-Chronicles-Emulator/game-server) | Characters, world simulation, gameplay and operator API |
| [**Launcher**](https://github.com/Project-Chronicles-Emulator/launcher) | Player desktop interface, client selection and startup |
| [**Admin**](https://github.com/Project-Chronicles-Emulator/admin) | Operator desktop console and server management |

## Research tools

- [SDK generator](https://github.com/Project-Chronicles-Emulator/sdk-generator): generate your own reflection/C++/Lua SDK from a compatible local client.
- [Asset extractor](https://github.com/Project-Chronicles-Emulator/asset-extractor): extract your own archives and prepare verified catalogs.

Both repositories contain project source and guides only, with no game files, generated game exports or keys.

## Start with a clear path

- **Run locally:** follow the [four-component setup](https://github.com/Project-Chronicles-Emulator/game-server/blob/main/docs/guides/getting-started.md).
- **Prepare game content:** use the [archive and runtime-data pipeline](https://github.com/Project-Chronicles-Emulator/game-server/blob/main/docs/guides/game-data.md).
- **Understand current support:** read the [feature matrix](https://github.com/Project-Chronicles-Emulator/game-server/blob/main/docs/progress.md) and its evidence links.
- **Build a feature or fix a bug:** begin with [contribution guidance](https://github.com/Project-Chronicles-Emulator/game-server/blob/main/CONTRIBUTING.md).

This is an experimental, build-specific emulator. Feature status, static research,
synthetic checks and original-client observations are kept separate. Source repositories
include no game client, extracted assets, archive keys or deployment credentials.
